# mp-project6-codebreaking
MATH20014 group project 6 – code breaking with statistical physics
How we use this repo
- The notebook in `main` is the ONE current version. Nobody keeps a private copy in sync by hand.
- One person at a time edits the notebook. Announce in the group chat before you upload it.
- Before uploading, check the file's History to make sure nobody else committed after you last downloaded it.
- Everyone else uploads separate files (their own Core section, figures, scripts), not the notebook.
- Backup rule: also save the notebook as `Core_Exercises_<date>_<yourname>.ipynb` before a big edit.
